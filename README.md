# RSB — Workspaces por idioma

Este repositorio contiene 10 espacios de trabajo independientes, uno por idioma, derivados del paquete auditado.

## Uso

Cada chat debe trabajar exclusivamente con su carpeta:

- `IDIOMAS/EN/`
- `IDIOMAS/ES/`
- `IDIOMAS/FR/`
- `IDIOMAS/IT/`
- `IDIOMAS/DE/`
- `IDIOMAS/NL/`
- `IDIOMAS/PT/`
- `IDIOMAS/CA/`
- `IDIOMAS/SV/`
- `IDIOMAS/PL/`

El prompt listo para copiar de cada idioma está en `PROMPTS/<IDIOMA>.txt` y también dentro de cada carpeta como `05_PROMPT_GITHUB_<IDIOMA>.txt`.

## Datos canónicos fijados por el propietario

- Reseñas: **226**. No sustituir por 222.
- Reserva: **30 % por transferencia para confirmar + 70 % al recoger**.
- Depósito scooter de referencia: **250 €**.
- Sin depósito: bicicletas, patines en línea, patines clásicos, skateboards y longboards.
- Radio de servicio: **25 km**.
- Google Maps API: el propietario confirma que la clave está restringida; no eliminarla por ser visible en cliente.
- No se ofrecen e-scooters ni e-bikes.

## Regla de alcance

Los chats por idioma no deben modificar archivos raíz compartidos, CSS, JS, JSON, XML, configuración ni imágenes físicas salvo autorización expresa del prompt de ese idioma.

La evidencia compartida legible está en `AUDITORIA_COMPARTIDA/`. Los archivos fuente originales permanecen en la raíz del repositorio.
